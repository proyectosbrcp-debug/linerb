# Checklist de usabilidad en campo

## Preparación

- [ ] Instalar APK debug en teléfono Android pequeño.
- [ ] Probar con brillo alto y bajo.
- [ ] Probar con conectividad normal, lenta y sin señal.
- [ ] Probar con escala de texto 1.0, 1.3, 1.5 y 2.0.

## Login

- [ ] Iniciar sesión con usuario válido.
- [ ] Verificar teclado de email.
- [ ] Verificar autofill.
- [ ] Mostrar y ocultar contraseña.
- [ ] Intentar doble toque en iniciar sesión.
- [ ] Verificar error genérico ante credenciales inválidas.

## Inspección

- [ ] Seleccionar tipo de línea.
- [ ] Seleccionar línea.
- [ ] Ingresar responsable.
- [ ] Obtener coordenadas.
- [ ] Tomar Foto 1.
- [ ] Tomar Foto 2.
- [ ] Agregar hallazgo.
- [ ] Intentar doble toque en agregar hallazgo.
- [ ] Guardar borrador.
- [ ] Cerrar y restaurar borrador.
- [ ] Finalizar inspección.
- [ ] Intentar doble toque en finalizar.

## Resumen y PDF

- [ ] Revisar resumen antes de guardar.
- [ ] Confirmar y guardar una sola vez.
- [ ] Generar PDF sin cambios visuales respecto al Sprint 4.6.
- [ ] Confirmar que fotografías y PDF quedan locales.

## Historial

- [ ] Ver historial vacío.
- [ ] Ver historial con inspecciones.
- [ ] Revisar paginación.
- [ ] Revisar fin de lista.

## Avance

- [ ] Revisar líneas verdes, amarillas y rojas.
- [ ] Confirmar que cada estado tiene color, icono y texto.
- [ ] Confirmar lectura de “Nunca inspeccionada”.

## Dashboard

- [ ] Revisar indicadores.
- [ ] Revisar filtros activos.
- [ ] Revisar detalles de prioridad.
- [ ] Revisar detalle de hallazgos.
- [ ] Confirmar que dashboard usa SQLite y no Firestore.

## Sincronización

- [ ] Revisar indicador discreto.
- [ ] Sincronizar manualmente.
- [ ] Probar offline.
- [ ] Recuperar señal.
- [ ] Confirmar que no se sincronizan fotos, rutas, PDF, mapas ni borradores.

## Cierre

- [ ] Cerrar sesión.
- [ ] Volver a iniciar sesión.
- [ ] Confirmar que no se pierden datos locales.
